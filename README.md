# Khizar Ali Shah — Portfolio

Personal portfolio of Khizar Ali Shah (eros98), penetration tester, security engineer and open-source vulnerability researcher.

Live: https://porfolio-sepia-ten.vercel.app

## Editing

All content (bio, CVEs, projects, experience, contact) lives in [`src/content/site.ts`](src/content/site.ts). The layout is in [`src/app/page.tsx`](src/app/page.tsx).

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Stack

Next.js and Tailwind CSS, deployed on Vercel.
